# Font provenance

The logo artwork uses outlined glyphs from two Google Fonts font files. Font binaries
are not embedded in SVGs or distributed in this repository. No system font was installed.

The binaries used were 136,676 and 876,576 bytes. On 2026-09-30 their Git blob
hashes were compared, without downloading any file, with read-only GitHub
repository metadata. Each matches the file added by the commit named above, which is
the only upstream commit touching that path. On that date the same blobs were also
present on the `main` branch.

Both fonts are under the SIL Open Font License, Version 1.1. See the
[Space Grotesk notice](licenses/SpaceGrotesk-OFL.txt) and
[Inter notice](licenses/Inter-OFL.txt). Each notice is the `OFL.txt` from the same
upstream commit and directory. The Inter notice is byte-identical to its upstream
blob (`21f6aff961064c2e429f570995e446bcdd555422`). The Space Grotesk notice has the
same text as its upstream blob (`cb512b9af44ff61e75e1aad387b7424cdfab36a3`), with
CRLF line endings normalized to LF. These notices do not license CDS itself.

Outlines were generated using FontTools 4.66.1 from the variable fonts. Space
Grotesk was instanced at wght=600; Inter at wght=400, opsz=24.

## Acquisition and authorization

The source provenance above does not show that obtaining the font files was
authorized. The files were downloaded to a local working folder outside this
repository during the earlier Public Identity & README execution. No record of an
explicit Human-Maintainer authorization for that download has been found. This is
recorded as an open historical process gap. It is neither resolved nor excused here.
