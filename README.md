# Core Design System

The Core Design System (CDS) is the central design, brand, user-experience,
and interface foundation for the Core product ecosystem.

## Project status

**Foundation phase — pre-design**

No final decisions have been made regarding:

- brand identity,
- logos,
- colors,
- typography,
- icons,
- design tools,
- component frameworks,
- token tooling,
- documentation platforms.

## Initial consumer

CoreOps will serve as the first reference consumer of stable CDS foundations
and components.

CoreOps is a reference consumer, not the sole design target.

## Operating model

This project follows the Nova Development Framework v1.0.0.

- Nova: strategy, architecture, planning, review, and project control
- Claude: scoped analysis and implementation
- Cursor: primary development environment
- Human Maintainer: approval, commit, push, tag, and release authority
