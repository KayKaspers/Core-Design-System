# Next Phase

## Active work package

CDS-WP-001 — Project Governance and NDF Bootstrap

## Objective

Create the controlled repository and governance foundation required before
design research, brand strategy, token architecture, or implementation begins.

## Allowed activities

- establish the project directory and repository,
- establish initial NDF control files,
- define project roles and authority boundaries,
- establish initial Claude operating instructions,
- record the strategic project purpose,
- prepare the repository for NDF Skills Bootstrap,
- identify missing governance artifacts.

## Explicitly prohibited

- selecting colors,
- creating or selecting logos,
- selecting typography,
- selecting icon systems,
- selecting design or component tools,
- selecting token tooling,
- selecting application frameworks,
- importing third-party design assets,
- making public compatibility promises,
- publishing a release.

## Expected outcome

A minimal, internally consistent, reviewable project foundation.
